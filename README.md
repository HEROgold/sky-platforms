# Sky Platforms

A Factorio 2.1 Space Age mod (working name). You start in orbit on a space platform with no character body. You build a basic factory on one or more platforms, then land on short-lived planets to grab bulk or special resources, such as uranium, before a timer forces you back up. Landing uses the [Thud](https://mods.factorio.com/mod/Thud) mod. Everything else stays close to vanilla.

Status: phase 0, research and setup. There is no playable build yet.

## How work is tracked

- Issues and the [project board](https://github.com/users/HEROgold/projects/13) track every idea, design, spec, slice, bug and research question.
- Work flows Idea, then Design, then Spec, then Slice. A slice is one player-visible change that ships on its own. See [docs/README.md](docs/README.md).
- Every issue says why we need it. Specs and slices also say how the change reaches the mod portal.
- Research notes live in [docs/research/](docs/research/).
